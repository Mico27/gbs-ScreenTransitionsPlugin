# ScreenTransitionsPlugin — unit test projects

Generated by `generate_test_projects.js` in the GBStudio Plugin Patch Builder. Each folder is
a GB Studio project that installs this plugin in one configuration and exists to prove that
configuration still compiles. Build them all with `build_examples.js --tests`.

Every project carries one scene of each scene type, because GB Studio only compiles the state
file for a scene type the project uses.

| Project | What it covers |
|---|---|
| `DEFAULT` | ScreenTransitionsPlugin on its own, every engine setting at its default. |
| `ALT_Cont_M` | ScreenTransitionsPlugin with ContinuousScenePlugin, MetaTilePlugin — selects engineAlt/Cont_M. |
| `ALT_ScreenS_M` | ScreenTransitionsPlugin with ScreenScrollPlugin, MetaTilePlugin — selects engineAlt/ScreenS_M. |
| `ALT_Cont` | ScreenTransitionsPlugin with ContinuousScenePlugin — selects engineAlt/Cont. |
| `ALT_M` | ScreenTransitionsPlugin with MetaTilePlugin — selects engineAlt/M. |
| `ALT_ScreenS` | ScreenTransitionsPlugin with ScreenScrollPlugin — selects engineAlt/ScreenS. |
